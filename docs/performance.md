# 性能测量边界

以下是 2026-09-18 留存的合成页面测量，使用既有原生动效样式、玻璃背景及 20 Hz 文本更新。它们不是 0.4.5 在所有设备上的性能承诺，也不是实际用户视频掉帧测试。0.4.5 保留这些动效实现，新增变化是 DSH alpha.2 的折叠兼容。

## 合成层文字流光与帧率

Windows Chrome 153，1704×870，DPR 1.5；该次环境 rAF 回调约 280 Hz。相同合成页面同时运行 60 FPS 的主题等高线，每档两次、每次约两秒：

| 流光设置 | 平均 Paint 事件 | 平均 Paint 时长 ms |
| --- | ---: | ---: |
| 跟随屏幕 | 1729 | 52.2 |
| 24 FPS | 266 | 13.8 |
| 60 FPS | 410 | 16.3 |

各档 Layout 均为 40 次，rAF 间隔 p95 约 3.7 ms。Paint 是整个合成页面的 trace 事件，包含主题和文本开销；不能换算为 GPU 总占用或视频掉帧改善比例。

## WebGL 与默认合成层

另一次相同尺寸的 Windows Chrome 测试中，rAF 回调约 32 Hz。这个环境与上一组不同，不应跨表直接比较。每项两次、每次约两秒，两个文字流光均确认使用目标后端：

| 流光设置 | 后端 | 平均 Paint 事件 | 主线程 TaskDuration ms |
| --- | --- | ---: | ---: |
| 跟随屏幕 | 合成层 | 235.5 | 76.8 |
| 跟随屏幕 | WebGL | 232.0 | 86.3 |
| 24 FPS | 合成层 | 196.0 | 71.8 |
| 24 FPS | WebGL | 200.5 | 83.6 |
| 60 FPS | 合成层 | 232.0 | 68.0 |
| 60 FPS | WebGL | 233.5 | 81.9 |

rAF p95 约 31.6–31.7 ms，没有稳定改善，WebGL 的任务用时略高。因此 WebGL 保持试验选项，默认合成层。

24 组历史像素对比覆盖 DPR 1/1.5/2、明暗背景和四个相位，最大单通道差 2/255；这不承诺所有字形、颜色空间或设备都逐像素相同。复杂效果会保留原生或回退合成层。

复测应分别记录插件模式、帧率、渲染后端、DSH 与主题版本、设备与浏览器、实际显示/回调频率、文本更新负载、预热和重复次数。区分 Paint、Layout、主线程时间与最终帧呈现，不把主题动画或流式正文开销归给本插件。
